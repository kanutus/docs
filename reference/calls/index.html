    GET/v1/calls/quote#

    Quote a destination and check the call purpose for that country

    Permission: calls:read

    Parameters

    NameTypeDescription
    to requiredquery · string
    purposequery · "transactional" | "scheduling" | "support" | "marketing"
    consentquery · "existing_customer" | "prior_express" | "written"
    fromquery · string

    Response 200

    NameTypeDescription
    to requiredstringMasked number
    country requiredstring
    kind requiredstring
    allowed requiredboolean
    minute_factor requirednumber
    reason requiredstring
    purpose requiredobject | null
    purpose.purpose required"transactional" | "scheduling" | "support" | "marketing"
    purpose.allowed requiredboolean
    purpose.code requiredstring
    purpose.message requiredstring | null
    purpose.requires requiredstring[]
    purpose.legal_reviewed requiredboolean
    simulator requiredstring | null

    POST/v1/calls#

    Place a translated call as an AI agent (always announces it is an AI) Soon

    Permission: calls:dial

    Live mode answers 501 coming soon. Try it now with a kt_test_ key (simulator).

    Parameters

    NameTypeDescription
    idempotency-key requiredheader · stringUnique key per create request; retries with the same key return the same result.

    Request body

    NameTypeDescription
    to requiredstringlength 4–32
    fromstringCaller ID (one of the organization's numbers) · length 0–32
    purpose required"transactional" | "scheduling" | "support" | "marketing"
    consentobject
    consent.kind required"existing_customer" | "prior_express" | "written"
    consent.refstringYour reference to the consent record · length 0–200
    agent_langstringdefault "en"
    remote_langstring
    voice_idstringlength 0–100

    Response 201

    NameTypeDescription
    id requiredstring
    to requiredstring
    country requiredstring
    purpose required"transactional" | "scheduling" | "support" | "marketing"
    status required"queued" | "ringing" | "answered" | "completed" | "busy" | "voicemail" | "no_answer" | "failed" | "blocked"
    ai_disclosure requiredtrue
    billed_seconds requiredinteger
    created_at requiredstring
    answered_atstring | null
    ended_atstring | null
    end_reasonstring | nullagent_hangup, remote_hangup, max_duration, busy, voicemail, no_answer…
    livemode requiredboolean

    Example

    curl
    curl -X POST "https://api.kanutus.com/v1/calls" \
  -H "Authorization: Bearer $KANUTUS_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"to":"+1 555 0100","from":"string","purpose":"transactional","consent":{"kind":"existing_customer","ref":"string"},"agent_lang":"en","remote_lang":"string","voice_id":"string"}'
    Node.js
    const res = await fetch("https://api.kanutus.com/v1/calls", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.KANUTUS_API_KEY}`,
    "Idempotency-Key": crypto.randomUUID(),
    "Content-Type": "application/json",
  },
  body: JSON.stringify({"to":"+1 555 0100","from":"string","purpose":"transactional","consent":{"kind":"existing_customer","ref":"string"},"agent_lang":"en","remote_lang":"string","voice_id":"string"}),
});
console.log(res.status, await res.json());
    Python
    import os, uuid, requests

r = requests.request(
    "POST",
    "https://api.kanutus.com/v1/calls",
    headers={"Authorization": f"Bearer {os.environ['KANUTUS_API_KEY']}", "Idempotency-Key": str(uuid.uuid4())},
    json={"to":"+1 555 0100","from":"string","purpose":"transactional","consent":{"kind":"existing_customer","ref":"string"},"agent_lang":"en","remote_lang":"string","voice_id":"string"},
)
print(r.status_code, r.json())
