Transcripts

    GET/v1/transcripts#

    Transcripts this credential can read

    Permission: transcripts:read

    Parameters

    NameTypeDescription
    room_idquery · string

    Response 200

    NameTypeDescription
    data requiredobject[]
    data[].id requiredstring
    data[].room_id requiredstring | null
    data[].started_at requiredstring
    data[].ended_at requiredstring | null
    data[].segments requiredinteger
    data[].livemode requiredboolean

    Example

    curl
    curl "https://api.kanutus.com/v1/transcripts" \
  -H "Authorization: Bearer $KANUTUS_API_KEY"
    Node.js
    const res = await fetch("https://api.kanutus.com/v1/transcripts", {
  method: "GET",
  headers: {
    Authorization: `Bearer ${process.env.KANUTUS_API_KEY}`,
  },
});
console.log(res.status, await res.json());
    Python
    import os, uuid, requests

r = requests.request(
    "GET",
    "https://api.kanutus.com/v1/transcripts",
    headers={"Authorization": f"Bearer {os.environ['KANUTUS_API_KEY']}"},
)
print(r.status_code, r.json())
    Try it

    Runs from your browser against the real API. Use a kt_test_ key: nothing is charged. The key stays in this tab only.

    GET/v1/transcripts/{id}#

    Read a transcript

    Permission: transcripts:read

    Parameters

    NameTypeDescription
    id requiredpath · string
    langquery · string

    Response 200

    NameTypeDescription
    id requiredstring
    room_id requiredstring | null
    lang requiredstring
    notice requiredstring
    segments requiredobject[]
    segments[].speaker requiredstring | null
    segments[].src_lang requiredstring | null
    segments[].untrusted_content requiredobject
    segments[].untrusted_content.text requiredstring | null
    segments[].untrusted_content.text_in_lang requiredstring | null
    segments[].at requiredstring

    Example

    curl
    curl "https://api.kanutus.com/v1/transcripts/ses_4fQ2xWm9Lr7Tb1Kc8Zp3Vd5N" \
  -H "Authorization: Bearer $KANUTUS_API_KEY"
    Node.js
    const res = await fetch("https://api.kanutus.com/v1/transcripts/ses_4fQ2xWm9Lr7Tb1Kc8Zp3Vd5N", {
  method: "GET",

    Authorization: `Bearer ${process.env.KANUTUS_API_KEY}`,
  },
});
console.log(res.status, await res.json());
