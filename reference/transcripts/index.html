Transcripts

GET/v1/transcripts#

Transcripts this credential can read

Permission: transcripts:read

Parameters

NameTypeDescription
room_idquery · string

Response 200

NameTypeDescription
data requiredobject[]
data[].id requiredstring
data[].room_id requiredstring | null
data[].started_at requiredstring
data[].ended_at requiredstring | null
data[].segments requiredinteger
data[].livemode requiredboolean

Example

curl
curl "https://api.kanutus.com/v1/transcripts" \
  -H "Authorization: Bearer $KANUTUS_API_KEY"
200
{
  "data": [
    {
      "id": "string",
      "room_id": "string",
      "started_at": "string",
      "ended_at": "string",
      "segments": 0,
      "livemode": true
    }
  ]
}

Errors: 400 401 403 429

GET/v1/transcripts/{id}#

Read a transcript

Permission: transcripts:read

Parameters

NameTypeDescription
id requiredpath · string
langquery · string

Response 200

NameTypeDescription
id requiredstring
room_id requiredstring | null
lang requiredstring
notice requiredstring
segments requiredobject[]
segments[].speaker requiredstring | null
segments[].src_lang requiredstring | null
segments[].untrusted_content requiredobject
segments[].untrusted_content.text requiredstring | null
segments[].untrusted_content.text_in_lang requiredstring | null
segments[].at requiredstring

Example

curl
curl "https://api.kanutus.com/v1/transcripts/ses_4fQ2xWm9Lr7Tb1Kc8Zp3Vd5N" \
  -H "Authorization: Bearer $KANUTUS_API_KEY"
200
{
  "id": "string",
  "room_id": "string",
  "lang": "string",
  "notice": "string",
  "segments": [
    {
      "speaker": "string",
      "src_lang": "string",
      "untrusted_content": {
        "text": "string",
        "text_in_lang": "string"
      },
      "at": "string"
    }
  ]
}

Errors: 400 401 403 404 429
