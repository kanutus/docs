Account and usage

GET/v1/me#

Who am I: organization, permissions and limits of this credential

Permission: any valid credential

Response 200

NameTypeDescription
credential requiredobject
credential.kind required"key" | "oauth" | "client"key = API key, oauth = app connected by a person, client = organization app
credential.id requiredstring
credential.name requiredstring
credential.mode required"live" | "test"
credential.needs_review requiredboolean
organization requiredobject | null
organization.id requiredstring
organization.name requiredstring
user requiredobject | null
user.id requiredstring
user.name requiredstring | null
permissions requiredstring[]
limits requiredobject
limits.spend_day_minutes requirednumber | null
limits.spend_month_minutes requirednumber | null
limits.per_call_minutes requirednumber | null
limits.requests_per_minute requirednumber
limits.spent_today_minutes requirednumber
limits.spent_month_minutes requirednumber
pricing requiredobject
pricing.api_minute_factor requirednumber
pricing.listen_text_factor requirednumber

Example

curl
curl "https://api.kanutus.com/v1/me" \
  -H "Authorization: Bearer $KANUTUS_API_KEY"
200
{
  "credential": {
    "kind": "key",
    "id": "string",
    "name": "string",
    "mode": "live",
    "needs_review": true
  },
  "organization": {
    "id": "string",
    "name": "string"
  },
  "user": {
    "id": "string",
    "name": "string"
  },
  "permissions": [
    "string"
  ],
  "limits": {
    "spend_day_minutes": 0,
    "spend_month_minutes": 0,
    "per_call_minutes": 0,
    "requests_per_minute": 0,
    "spent_today_minutes": 0,
    "spent_month_minutes": 0
  },
  "pricing": {
    "api_minute_factor": 0,
    "listen_text_factor": 0
  }
}

Errors: 400 401 403 429

GET/v1/balance#

Minutes left (organization pool/quota or personal plan)

Permission: usage:read

Response 200

NameTypeDescription
minutes_left requirednumber
seconds_left requiredinteger
low requiredboolean
source required"organization" | "personal" | "test"
livemode requiredboolean

Example

curl
curl "https://api.kanutus.com/v1/balance" \
  -H "Authorization: Bearer $KANUTUS_API_KEY"
200
{
  "minutes_left": 0,
  "seconds_left": 0,
  "low": true,
  "source": "organization",
  "livemode": true
}

Errors: 400 401 403 429

GET/v1/usage#

API usage by day or by credential

Permission: usage:read

Parameters

NameTypeDescription
fromquery · string
toquery · string
group_byquery · "day" | "credential"

Response 200

NameTypeDescription
from requiredstring
to requiredstring
total_minutes requirednumber
requests requiredinteger
errors requiredinteger
data requiredobject[]
data[].daystring
data[].credential_idstring
data[].namestring
data[].minutes requirednumber
data[].requestsinteger

Example

curl
curl "https://api.kanutus.com/v1/usage" \
  -H "Authorization: Bearer $KANUTUS_API_KEY"
200
{
  "from": "string",
  "to": "string",
  "total_minutes": 0,
  "requests": 0,
  "errors": 0,
  "data": [
    {
      "day": "string",
      "credential_id": "string",
      "name": "string",
      "minutes": 0,
      "requests": 0
    }
  ]
}

Errors: 400 401 403 429
