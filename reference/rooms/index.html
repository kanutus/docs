GET/v1/rooms#

List rooms

Permission: rooms:read

Parameters

NameTypeDescription
limitquery · integer

Response 200

NameTypeDescription
data requiredobject[]
data[].id requiredstring
data[].url requiredstring
data[].title requiredstring
data[].visibility required"private" | "public"
data[].status required"scheduled" | "live" | "ended"
data[].created_at requiredstring
data[].expires_at requiredstring
data[].starts_at requiredstring | null
data[].duration_min requiredinteger | null
data[].invitees requiredstring[]
data[].langs requiredstring[]
data[].livemode requiredbooleanfalse for objects created with a kt_test_ key (simulator).

curl
curl "https://api.kanutus.com/v1/rooms" \
  -H "Authorization: Bearer $KANUTUS_API_KEY"

      "duration_min": 0,
      "invitees": [
        "string"
      ],
      "langs": [
        "string"
      ],
      "livemode": true
    }
  ]
}

POST/v1/rooms#

Create an instant room

Permission: rooms:write

Parameters

NameTypeDescription
idempotency-key requiredheader · stringUnique key per create request; retries with the same key return the same result.

Request body

NameTypeDescription
titlestringlength 0–120 · default ""
visibility"private" | "public"default "private"
langsstring[]Languages expected in the room (helps warm-up).

Response 201

NameTypeDescription
id requiredstring
url requiredstring
title requiredstring
visibility required"private" | "public"
status required"scheduled" | "live" | "ended"
created_at requiredstring
expires_at requiredstring
starts_at requiredstring | null
duration_min requiredinteger | null
invitees requiredstring[]
langs requiredstring[]
livemode requiredbooleanfalse for objects created with a kt_test_ key (simulator).

Example

curl
curl -X POST "https://api.kanutus.com/v1/rooms" \
  -H "Authorization: Bearer $KANUTUS_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"title":"Proposta com a Andes","visibility":"private","langs":[]}'
201
{
  "id": "kqz-mbdt-wpa",
  "url": "https://example.com",
  "title": "string",
  "visibility": "private",
  "status": "scheduled",
  "created_at": "string",
  "expires_at": "string",
  "starts_at": "string",
  "duration_min": 0,
  "invitees": [
    "string"
  ],
  "langs": [
    "string"
  ],
  "livemode": true
}

Errors: 400 401 403 409 429

POST/v1/rooms/{id}/join-links#

Create a guest join link (name and language prefilled)

Permission: rooms:write

Parameters

NameTypeDescription
id requiredpath · string

Request body

NameTypeDescription
namestringlength 1–80
speakstringLanguage the guest speaks (prefilled).
hearstringLanguage the guest wants to hear (prefilled).

Response 201

NameTypeDescription
url requiredstring
room_id requiredstring

Example

curl
curl -X POST "https://api.kanutus.com/v1/rooms/kqz-mbdt-wpa/join-links" \
  -H "Authorization: Bearer $KANUTUS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"Kenji","speak":"pt","hear":"pt"}'
201
{
  "url": "https://example.com",
  "room_id": "string"
}

Errors: 400 401 403 404 429
