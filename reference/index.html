API reference

    Generated from the API's OpenAPI 3.1 file (also at https://api.kanutus.com/v1/openapi.json). Every endpoint has examples in curl, Node.js and Python, responses by status and a Try it panel that calls the real API with your test key. Press / to search.

    #Base URL

    text
    https://api.kanutus.com/v1

    #Authentication

    http
    Authorization: Bearer kt_live_...

    An API key or an OAuth access token. See Authentication.

    #Conventions

    • JSON in and out (Content-Type: application/json). Dates in ISO 8601, times in UTC unless they carry an offset.
    • POST requests that create something need Idempotency-Key (why).
    • Objects created with a test key have &quot;livemode&quot;: false.
    • Lists come in { &quot;data&quot;: [...] }.
    • Errors: application/problem+json with a stable code (list).
