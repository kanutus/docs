Avatares

    GET/v1/avatars#

    Listar os avatares publicados da Kanutus: cada pessoa vem em variações (ângulos e ambientes) com os vídeos de comportamento que você pode escolher

    Permissão: voices:read

    Resposta 200

    NomeTipoDescrição
    data obrigatórioobject[]
    data[].id obrigatóriostring
    data[].name obrigatóriostring
    data[].gender obrigatório"female" | "male" | "other" | null
    data[].age_band obrigatório"25-35" | "36-50" | "51-65" | null
    data[].style obrigatório"formal" | "casual" | null
    data[].poster_url obrigatóriostring | nullCover image (the first variation's photo when there is no dedicated cover)
    data[].variations obrigatórioobject[]
    data[].variations[].code obrigatóriostringa1–a3: same setting, different angles · v1–v3: another setting and outfit
    data[].variations[].kind obrigatório"angle" | "scene"
    data[].variations[].photo_url obrigatóriostring | nullStill photo of this variation
    data[].variations[].video_types obrigatório"talk-neutral" | "talk-agree" | "idle-aside" | "idle-monitor" | "talk-explain" | "talk-question"[]Behavior clips you can pick for this variation (talk-neutral first)
    data[].variations[].preview_urls obrigatórioobjectShort preview clip per video type (null = no preview yet; show the photo)
    data[].suggested_voices obrigatórioobjectSuggested voice per language, e.g. {&quot;pt&quot;: &quot;kt-pt-f-03&quot;, &quot;en&quot;: &quot;kt-en-f-06&quot;}: catalog voice keys you can pass as voice_id when joining a room with this avatar.

    Exemplo

    curl
    curl "https://api.kanutus.com/v1/avatars" \
  -H "Authorization: Bearer $KANUTUS_API_KEY"
    Node.js
    const res = await fetch("https://api.kanutus.com/v1/avatars", {
  method: "GET",
  headers: {
    Authorization: `Bearer ${process.env.KANUTUS_API_KEY}`,
  },
});
console.log(res.status, await res.json());
    Python
    import os, uuid, requests

r = requests.request(
    "GET",
    "https://api.kanutus.com/v1/avatars",
    headers={"Authorization": f"Bearer {os.environ['KANUTUS_API_KEY']}"},
)
print(r.status_code, r.json())
