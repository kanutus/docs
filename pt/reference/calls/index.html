GET/v1/calls/quote#

Cotar um destino e conferir a finalidade da ligação naquele país

Permissão: calls:read

Parâmetros

NomeTipoDescrição
to obrigatórioquery · string
purposequery · "transactional" | "scheduling" | "support" | "marketing"
consentquery · "existing_customer" | "prior_express" | "written"
fromquery · string

Resposta 200

NomeTipoDescrição
to obrigatóriostringMasked number
country obrigatóriostring
kind obrigatóriostring
allowed obrigatórioboolean
minute_factor obrigatórionumber
reason obrigatóriostring
purpose obrigatórioobject | null
purpose.purpose obrigatório"transactional" | "scheduling" | "support" | "marketing"
purpose.allowed obrigatórioboolean
purpose.code obrigatóriostring
purpose.message obrigatóriostring | null
purpose.requires obrigatóriostring[]
purpose.legal_reviewed obrigatórioboolean
simulator obrigatóriostring | null

Exemplo

curl
curl "https://api.kanutus.com/v1/calls/quote?to=string" \
  -H "Authorization: Bearer $KANUTUS_API_KEY"
200

  "kind": "string",

    "purpose": "transactional",

      "string"
    ],

  },

POST/v1/calls#

Fazer uma ligação traduzida como agente de IA (sempre se anuncia como IA) Em breve

Permissão: calls:dial

Em produção responde 501 (em breve). Já dá para testar com uma chave kt_test_ (simulador).

Parâmetros

NomeTipoDescrição
idempotency-key obrigatórioheader · stringUnique key per create request; retries with the same key return the same result.

Corpo da requisição

NomeTipoDescrição
to obrigatóriostringlength 4–32
fromstringCaller ID (one of the organization's numbers) · length 0–32
purpose obrigatório"transactional" | "scheduling" | "support" | "marketing"
consentobject
consent.kind obrigatório"existing_customer" | "prior_express" | "written"
consent.refstringYour reference to the consent record · length 0–200
agent_langstringdefault "en"
remote_langstring
voice_idstringlength 0–100

Resposta 201

NomeTipoDescrição
id obrigatóriostring
to obrigatóriostring
country obrigatóriostring
purpose obrigatório"transactional" | "scheduling" | "support" | "marketing"
status obrigatório"queued" | "ringing" | "answered" | "completed" | "busy" | "voicemail" | "failed" | "blocked"
ai_disclosure obrigatóriotrue
billed_seconds obrigatóriointeger
created_at obrigatóriostring
livemode obrigatórioboolean

Exemplo

curl
curl -X POST "https://api.kanutus.com/v1/calls" \
  -H "Authorization: Bearer $KANUTUS_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"to":"+1 555 0100","from":"string","purpose":"transactional","consent":{"kind":"existing_customer","ref":"string"},"agent_lang":"en","remote_lang":"string","voice_id":"string"}'
201
{
  "id": "string",
  "to": "string",
  "country": "string",
  "purpose": "transactional",
  "status": "queued",
  "ai_disclosure": true,
  "billed_seconds": 0,
  "created_at": "string",
  "livemode": true
}

Erros: 400 401 402 403 409 429 501
