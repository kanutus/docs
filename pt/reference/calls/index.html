    GET/v1/calls/quote#

    Cotar um destino e conferir a finalidade da ligação naquele país

    Permissão: calls:read

    Parâmetros

    NomeTipoDescrição
    to obrigatórioquery · string
    purposequery · "transactional" | "scheduling" | "support" | "marketing"
    consentquery · "existing_customer" | "prior_express" | "written"
    fromquery · stringCaller number: the id of one of GET /v1/numbers (its E.164 is also accepted). Omitted = the default number.

    Resposta 200

    NomeTipoDescrição
    to obrigatóriostringMasked number
    country obrigatóriostring
    kind obrigatóriostring
    allowed obrigatórioboolean
    minute_factor obrigatórionumber
    reason obrigatóriostring
    purpose obrigatórioobject | null
    purpose.purpose obrigatório"transactional" | "scheduling" | "support" | "marketing"
    purpose.allowed obrigatórioboolean
    purpose.code obrigatóriostring
    purpose.message obrigatóriostring | null
    purpose.requires obrigatóriostring[]
    purpose.legal_reviewed obrigatórioboolean
    simulator obrigatóriostring | null
    from obrigatórioobject
    from.id obrigatóriostringNumber id: send it as from in POST /v1/calls
    from.e164 obrigatóriostring
    from.label obrigatóriostring | null
    from.status obrigatório"active"Only numbers that can call right now are listed
    from.shared obrigatóriobooleantrue = the Kanutus shared number (not your organization's own)
    from.default obrigatóriobooleanThe number used when from is not sent

    Exemplo

    curl
    curl "https://api.kanutus.com/v1/calls/quote?to=string" \
  -H "Authorization: Bearer $KANUTUS_API_KEY"
    Node.js
    const res = await fetch("https://api.kanutus.com/v1/calls/quote", {
  method: "GET",
  headers: {
    Authorization: `Bearer ${process.env.KANUTUS_API_KEY}`,
  },
});
console.log(res.status, await res.json());
    Python
    import os, uuid, requests

r = requests.request(
    "GET",
    "https://api.kanutus.com/v1/calls/quote",
    headers={"Authorization": f"Bearer {os.environ['KANUTUS_API_KEY']}"},
)
print(r.status_code, r.json())

    POST/v1/calls#

    Fazer uma ligação traduzida como agente de IA (sempre se anuncia como IA)

    Permissão: calls:dial

    Parâmetros

    NomeTipoDescrição
    idempotency-key obrigatórioheader · stringUnique key per create request; retries with the same key return the same result.

    Corpo da requisição

    NomeTipoDescrição
    to obrigatóriostringlength 4–32
    fromstringCaller number: the id of one of GET /v1/numbers (its E.164 is also accepted). Omitted = the default number. · length 1–64
    purpose obrigatório"transactional" | "scheduling" | "support" | "marketing"
    consentobject
    consent.kind obrigatório"existing_customer" | "prior_express" | "written"
    consent.refstringYour reference to the consent record · length 0–200
    agent_langstringLanguage code. Supported: pt, pt-PT, en, es, it, fr, de, nl, tr, zh, ja, ko, ru, pl, uk, sv, vi, da, nb, hi, ar, el, id, cs, fi, ro, hu. · default "en"
    remote_langstringLanguage code. Supported: pt, pt-PT, en, es, it, fr, de, nl, tr, zh, ja, ko, ru, pl, uk, sv, vi, da, nb, hi, ar, el, id, cs, fi, ro, hu.
    voice_idstringlength 0–100
    agent_namestringName shown in the organization's call history (default "AI assistant"). The person hears the AI notice with your organization's name. · length 1–80

    Resposta 201

    NomeTipoDescrição
    id obrigatóriostring
    to obrigatóriostring
    country obrigatóriostring
    purpose obrigatório"transactional" | "scheduling" | "support" | "marketing"
    status obrigatório"queued" | "ringing" | "answered" | "completed" | "busy" | "voicemail" | "no_answer" | "failed" | "blocked"
    ai_disclosure obrigatóriotrue
    billed_seconds obrigatóriointeger
    created_at obrigatóriostring
    answered_atstring | null
    ended_atstring | null
    end_reasonstring | nullagent_hangup, remote_hangup, max_duration, busy, voicemail, no_answer…
    ended_by"agent" | "remote" | "limit" | "system" | nullWho ended the call: agent (you hung up), remote (the person hung up, was busy or did not answer), limit (maximum duration or minutes) or system.
    session_idstring | nullAgent session inside the call: use say and listen (POST /v1/sessions/{id}/say, GET /v1/sessions/{id}/events) with it. Included in the call price.
    max_secondsinteger | nullThe call ends by itself after this many seconds of talk.
    livemode obrigatórioboolean

    Exemplo

    curl
    curl -X POST "https://api.kanutus.com/v1/calls" \
  -H "Authorization: Bearer $KANUTUS_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"to":"+1 555 0100","from":"9b2f6c1e-4d0a-4f55-8a43-2f1d6c7e0a11","purpose":"transactional","consent":{"kind":"existing_customer","ref":"string"},"agent_lang":"en","remote_lang":"string","voice_id":"string","agent_name":"Ava"}'
    Node.js
    const res = await fetch("https://api.kanutus.com/v1/calls", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.KANUTUS_API_KEY}`,
    "Idempotency-Key": crypto.randomUUID(),
    "Content-Type": "application/json",
  },
  body: JSON.stringify({"to":"+1 555 0100","from":"9b2f6c1e-4d0a-4f55-8a43-2f1d6c7e0a11","purpose":"transactional","consent":{"kind":"existing_customer","ref":"string"},"agent_lang":"en","remote_lang":"string","voice_id":"string","agent_name":"Ava"}),
});
console.log(res.status, await res.json());
    Python
    import os, uuid, requests

r = requests.request(
    "POST",
    "https://api.kanutus.com/v1/calls",
    headers={"Authorization": f"Bearer {os.environ['KANUTUS_API_KEY']}", "Idempotency-Key": str(uuid.uuid4())},
    json={"to":"+1 555 0100","from":"9b2f6c1e-4d0a-4f55-8a43-2f1d6c7e0a11","purpose":"transactional","consent":{"kind":"existing_customer","ref":"string"},"agent_lang":"en","remote_lang":"string","voice_id":"string","agent_name":"Ava"},
)
print(r.status_code, r.json())

    POST/v1/calls/{id}/dtmf#

    Apertar teclas do telefone (DTMF) em menus como "tecle 2 para vendas": 0-9, * e #, até 32

    Permissão: calls:dial

    Parâmetros

    NomeTipoDescrição
    id obrigatóriopath · string

    Corpo da requisição

    NomeTipoDescrição
    digits obrigatóriostring0-9, * and #; spaces and dashes are ignored · length 1–64

    Resposta 200

    NomeTipoDescrição
    id obrigatóriostring
    sent obrigatóriostring
    status obrigatório"queued" | "ringing" | "answered" | "completed" | "busy" | "voicemail" | "no_answer" | "failed" | "blocked"
    livemode obrigatórioboolean

    Exemplo

  -H "Content-Type: application/json" \
  -d '{"digits":"2#"}'
