Reuniões e agendamento

GET/v1/meetings#

Listar reuniões agendadas

Permissão: calendar:read

Parâmetros

NomeTipoDescrição
fromquery · string
toquery · string
limitquery · integer

Resposta 200

NomeTipoDescrição
data obrigatórioobject[]
data[].id obrigatóriostring
data[].url obrigatóriostring
data[].title obrigatóriostring
data[].visibility obrigatório"private" | "public"
data[].status obrigatório"scheduled" | "live" | "ended"
data[].created_at obrigatóriostring
data[].expires_at obrigatóriostring
data[].starts_at obrigatóriostring | null
data[].duration_min obrigatóriointeger | null
data[].invitees obrigatóriostring[]
data[].langs obrigatóriostring[]
data[].livemode obrigatóriobooleanfalse for objects created with a kt_test_ key (simulator).

Exemplo

curl
curl "https://api.kanutus.com/v1/meetings" \
  -H "Authorization: Bearer $KANUTUS_API_KEY"
200
{
  "data": [
    {
      "id": "kqz-mbdt-wpa",
      "url": "https://example.com",
      "title": "string",
      "visibility": "private",
      "status": "scheduled",
      "created_at": "string",
      "expires_at": "string",
      "starts_at": "string",
      "duration_min": 0,
      "invitees": [
        "string"
      ],
      "langs": [
        "string"
      ],
      "livemode": true
    }
  ]
}

Erros: 400 401 403 429

POST/v1/meetings#

Agendar uma reunião (sala com data, convidados e línguas)

Permissão: calendar:write

Parâmetros

NomeTipoDescrição
idempotency-key obrigatórioheader · stringUnique key per create request; retries with the same key return the same result.

Corpo da requisição

NomeTipoDescrição
title obrigatóriostringlength 1–120
starts_at obrigatóriostring
duration_mininteger5…720 · default 30
inviteesstring[]
langsstring[]Languages of the participants, e.g. ["pt", "ja"].
visibility"private" | "public"default "private"

Resposta 201

NomeTipoDescrição
id obrigatóriostring
url obrigatóriostring
title obrigatóriostring
visibility obrigatório"private" | "public"
status obrigatório"scheduled" | "live" | "ended"
created_at obrigatóriostring
expires_at obrigatóriostring
starts_at obrigatóriostring | null
duration_min obrigatóriointeger | null
invitees obrigatóriostring[]
langs obrigatóriostring[]
livemode obrigatóriobooleanfalse for objects created with a kt_test_ key (simulator).

Exemplo

curl
curl -X POST "https://api.kanutus.com/v1/meetings" \
  -H "Authorization: Bearer $KANUTUS_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"title":"Revisão com Kenji","starts_at":"2026-10-12T13:00:00-03:00","duration_min":30,"invitees":[],"langs":[],"visibility":"private"}'
201
{
  "id": "kqz-mbdt-wpa",
  "url": "https://example.com",
  "title": "string",
  "visibility": "private",
  "status": "scheduled",
  "created_at": "string",
  "expires_at": "string",
  "starts_at": "string",
  "duration_min": 0,
  "invitees": [
    "string"
  ],
  "langs": [
    "string"
  ],
  "livemode": true
}

Erros: 400 401 403 409 429

POST/v1/bookings#

Agendar um horário num link (seu ou de outra pessoa)

Permissão: calendar:write

Parâmetros

NomeTipoDescrição
idempotency-key obrigatórioheader · stringUnique key per create request; retries with the same key return the same result.

Corpo da requisição

NomeTipoDescrição
event_type_idstring
pagestringBooking page slug, when booking someone else's link
eventstringEvent slug on that page
start obrigatóriostring
guest obrigatórioobject
guest.name obrigatóriostringlength 1–80
guest.email obrigatóriostringlength 0–254
guest.speak obrigatóriostring
guest.hearstring
guest.tzstringlength 0–64 · default "UTC"
guest.localestringlength 0–8 · default "en"
answersobject

Resposta 201

NomeTipoDescrição
id obrigatóriostring
room_url obrigatóriostring | null
manage_url obrigatóriostring | null
start obrigatóriostring
livemode obrigatórioboolean

Exemplo

curl
curl -X POST "https://api.kanutus.com/v1/bookings" \
  -H "Authorization: Bearer $KANUTUS_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"event_type_id":"string","page":"string","event":"string","start":"2026-10-14T13:00:00Z","guest":{"name":"string","email":"ana@example.com","speak":"ja","hear":"string","tz":"UTC","locale":"en"},"answers":{}}'
201
{
  "id": "string",
  "room_url": "https://example.com",
  "manage_url": "https://example.com",
  "start": "string",
