Agente de IA na sala

POST/v1/rooms/{id}/agent-sessions#

Entrar na sala como agente de IA (texto entra, voz traduzida sai) Em breve

Permissão: rooms:join

Em produção responde 501 (em breve). Já dá para testar com uma chave kt_test_ (simulador).

Parâmetros

NomeTipoDescrição
id obrigatóriopath · string
idempotency-key obrigatórioheader · stringUnique key per create request; retries with the same key return the same result.

Corpo da requisição

NomeTipoDescrição
namestringlength 1–80 · default "Assistente de IA"
speak_lang obrigatóriostring
hear_lang obrigatóriostring
voice_idstringlength 0–100
announcebooleandefault true

Resposta 201

NomeTipoDescrição
id obrigatóriostring
room_id obrigatóriostring | null
name obrigatóriostring
speak_lang obrigatóriostring
hear_lang obrigatóriostring
status obrigatório"joining" | "active" | "ended"
billed_seconds obrigatóriointeger
started_at obrigatóriostring
ended_at obrigatóriostring | null
livemode obrigatórioboolean

Exemplo

curl
curl -X POST "https://api.kanutus.com/v1/rooms/kqz-mbdt-wpa/agent-sessions" \
  -H "Authorization: Bearer $KANUTUS_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"name":"Assistente da Vértice","speak_lang":"pt","hear_lang":"pt","voice_id":"string","announce":true}'
201
{
  "id": "string",
  "room_id": "string",
  "name": "string",
  "speak_lang": "string",
  "hear_lang": "string",
  "status": "joining",
  "billed_seconds": 0,
  "started_at": "string",
  "ended_at": "string",
  "livemode": true
}

Erros: 400 401 403 404 409 429 501

NomeTipoDescrição
