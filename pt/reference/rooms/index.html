GET/v1/rooms#

Listar salas

Permissão: rooms:read

Parâmetros

NomeTipoDescrição
limitquery · integer

Resposta 200

NomeTipoDescrição
data obrigatórioobject[]
data[].id obrigatóriostring
data[].url obrigatóriostring
data[].title obrigatóriostring
data[].visibility obrigatório"private" | "public"
data[].status obrigatório"scheduled" | "live" | "ended"
data[].created_at obrigatóriostring
data[].expires_at obrigatóriostring
data[].starts_at obrigatóriostring | null
data[].duration_min obrigatóriointeger | null
data[].invitees obrigatóriostring[]
data[].langs obrigatóriostring[]
data[].livemode obrigatóriobooleanfalse for objects created with a kt_test_ key (simulator).

Exemplo

curl
curl "https://api.kanutus.com/v1/rooms" \
  -H "Authorization: Bearer $KANUTUS_API_KEY"
200
{
  "data": [
    {
      "id": "kqz-mbdt-wpa",
      "url": "https://example.com",
      "title": "string",
      "visibility": "private",
      "status": "scheduled",
      "created_at": "string",
      "expires_at": "string",
      "starts_at": "string",
      "duration_min": 0,
      "invitees": [
        "string"
      ],
      "langs": [
        "string"
      ],
      "livemode": true
    }
  ]
}

Erros: 400 401 403 429

POST/v1/rooms#

Criar uma sala instantânea

Permissão: rooms:write

Parâmetros

NomeTipoDescrição
idempotency-key obrigatórioheader · stringUnique key per create request; retries with the same key return the same result.

Corpo da requisição

NomeTipoDescrição
titlestringlength 0–120 · default ""
visibility"private" | "public"default "private"
langsstring[]Languages expected in the room (helps warm-up).

Resposta 201

NomeTipoDescrição
id obrigatóriostring
url obrigatóriostring
title obrigatóriostring
visibility obrigatório"private" | "public"
status obrigatório"scheduled" | "live" | "ended"
created_at obrigatóriostring
expires_at obrigatóriostring
starts_at obrigatóriostring | null
duration_min obrigatóriointeger | null
invitees obrigatóriostring[]
langs obrigatóriostring[]
livemode obrigatóriobooleanfalse for objects created with a kt_test_ key (simulator).

Exemplo

curl
curl -X POST "https://api.kanutus.com/v1/rooms" \
  -H "Authorization: Bearer $KANUTUS_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"title":"Proposta com a Andes","visibility":"private","langs":[]}'
201
{
  "id": "kqz-mbdt-wpa",
  "url": "https://example.com",
  "title": "string",
  "visibility": "private",
  "status": "scheduled",
  "created_at": "string",
  "expires_at": "string",
  "starts_at": "string",
  "duration_min": 0,
  "invitees": [
    "string"
  ],
  "langs": [
    "string"
  ],
  "livemode": true
}

Erros: 400 401 403 409 429

POST/v1/rooms/{id}/join-links#

Criar link de convidado (nome e língua preenchidos)

Permissão: rooms:write

Parâmetros

NomeTipoDescrição
id obrigatóriopath · string

Corpo da requisição

NomeTipoDescrição
namestringlength 1–80
speakstringLanguage the guest speaks (prefilled).
hearstringLanguage the guest wants to hear (prefilled).

Resposta 201

NomeTipoDescrição
url obrigatóriostring
room_id obrigatóriostring

Exemplo

curl
curl -X POST "https://api.kanutus.com/v1/rooms/kqz-mbdt-wpa/join-links" \
  -H "Authorization: Bearer $KANUTUS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"Kenji","speak":"pt","hear":"pt"}'
201
{
  "url": "https://example.com",
  "room_id": "string"
}

Erros: 400 401 403 404 429
