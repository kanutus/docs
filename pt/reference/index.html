Referência da API

Esta referência é gerada a partir do arquivo OpenAPI 3.1 da API. Há também uma versão interativa em https://api.kanutus.com/docs.

#URL base

text
https://api.kanutus.com/v1

#Autenticação

http
Authorization: Bearer kt_live_...

Use uma chave de API ou um token de acesso OAuth. Veja Autenticação.

#Convenções

  • JSON na entrada e na saída (Content-Type: application/json). Datas em ISO 8601; horários em UTC, a não ser que tragam o fuso.
  • Requisições POST que criam algo precisam do Idempotency-Key (por quê).
  • Objetos criados com uma chave de teste vêm com &quot;livemode&quot;: false.
  • Listas vêm no formato { &quot;data&quot;: [...] }.
  • Erros: application/problem+json com um code estável (lista).
