    GET/v1/voices#

    Listar vozes (seus clones e as vozes genéricas escolhidas)

    Permissão: voices:read

    Resposta 200

    NomeTipoDescrição
    data obrigatórioobject[]
    data[].id obrigatóriostring
    data[].name obrigatóriostring
    data[].kind obrigatório"clone" | "generic"
    data[].active obrigatórioboolean
    data[].gender obrigatório"male" | "female" | null
    data[].status"awaiting_consent" | "processing" | "ready" | "failed" | "revoked" | "expired"Voices created through the API (consent flow). ready = usable in say.
    data[].consent_urlstring | nullSend this link to the person whose voice it is. They sign in with the email of the request, read the consent sentence and record live. Shown while awaiting consent.
    data[].languagestring
    data[].personobject
    data[].person.name obrigatóriostring
    data[].person.email obrigatóriostringMasked
    data[].failure_codestring | null
    data[].expires_atstring | null
    data[].created_atstring
    data[].livemodeboolean

    Exemplo

    POST/v1/voices#

    Clonar uma voz com consentimento verificável: devolve um link para a pessoa ler a frase de consentimento e gravar ao vivo Em breve

    Permissão: voices:clone

    Em produção responde 501 (em breve). Já dá para testar com uma chave kt_test_ (simulador).

    Parâmetros

    NomeTipoDescrição
    idempotency-key obrigatórioheader · stringUnique key per create request; retries with the same key return the same result.

    Corpo da requisição

    NomeTipoDescrição
    name obrigatóriostringlength 1–60
    language obrigatóriostringLanguage the person will read in (consent sentence: pt, en or es; others read in English).
    person obrigatórioobject
    person.name obrigatóriostringlength 1–80
    person.email obrigatóriostringThe person signs in with this email to give consent and record. · length 0–254

    Resposta 202

    NomeTipoDescrição
    id obrigatóriostring
    name obrigatóriostring
    kind obrigatório"clone" | "generic"
    active obrigatórioboolean
    gender obrigatório"male" | "female" | null
    status"awaiting_consent" | "processing" | "ready" | "failed" | "revoked" | "expired"Voices created through the API (consent flow). ready = usable in say.
    consent_urlstring | nullSend this link to the person whose voice it is. They sign in with the email of the request, read the consent sentence and record live. Shown while awaiting consent.
    languagestring
    personobject
    person.name obrigatóriostring
    person.email obrigatóriostringMasked
    failure_codestring | null
    expires_atstring | null
    created_atstring
    livemodeboolean

    Exemplo

    curl
    curl -X POST "https://api.kanutus.com/v1/voices" \
  -H "Authorization: Bearer $KANUTUS_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"name":"Ana (atendimento)","language":"pt","person":{"name":"Ana Ribeiro","email":"ana@vertice.com"}}'
    Node.js
    const res = await fetch("https://api.kanutus.com/v1/voices", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.KANUTUS_API_KEY}`,
    "Idempotency-Key": crypto.randomUUID(),
    "Content-Type": "application/json",
  },
  body: JSON.stringify({"name":"Ana (atendimento)","language":"pt","person":{"name":"Ana Ribeiro","email":"ana@vertice.com"}}),
});
console.log(res.status, await res.json());
    Python
    import os, uuid, requests

r = requests.request(
    "POST",
    "https://api.kanutus.com/v1/voices",
    headers={"Authorization": f"Bearer {os.environ['KANUTUS_API_KEY']}", "Idempotency-Key": str(uuid.uuid4())},
    json={"name":"Ana (atendimento)","language":"pt","person":{"name":"Ana Ribeiro","email":"ana@vertice.com"}},
)
print(r.status_code, r.json())
