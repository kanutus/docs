Vozes

    GET/v1/voices#

    Listar vozes (seus clones e as vozes genéricas escolhidas)

    Permissão: voices:read

    Resposta 200

    NomeTipoDescrição
    data obrigatórioobject[]
    data[].id obrigatóriostring
    data[].name obrigatóriostring
    data[].kind obrigatório"clone" | "generic"
    data[].active obrigatórioboolean
    data[].gender obrigatório"male" | "female" | null

    Exemplo

    curl
    curl "https://api.kanutus.com/v1/voices" \
  -H "Authorization: Bearer $KANUTUS_API_KEY"
    Node.js
    const res = await fetch("https://api.kanutus.com/v1/voices", {
  method: "GET",
  headers: {
    Authorization: `Bearer ${process.env.KANUTUS_API_KEY}`,
  },
});
console.log(res.status, await res.json());
    Python
    import os, uuid, requests

r = requests.request(
    "GET",
    "https://api.kanutus.com/v1/voices",
    headers={"Authorization": f"Bearer {os.environ['KANUTUS_API_KEY']}"},
)
print(r.status_code, r.json())
