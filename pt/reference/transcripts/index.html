Transcrições

GET/v1/transcripts#

Transcrições que esta credencial pode ler

Permissão: transcripts:read

Parâmetros

NomeTipoDescrição
room_idquery · string

Resposta 200

NomeTipoDescrição
data obrigatórioobject[]
data[].id obrigatóriostring
data[].room_id obrigatóriostring | null
data[].started_at obrigatóriostring
data[].ended_at obrigatóriostring | null
data[].segments obrigatóriointeger
data[].livemode obrigatórioboolean

Exemplo

curl
curl "https://api.kanutus.com/v1/transcripts" \
  -H "Authorization: Bearer $KANUTUS_API_KEY"
200
{
  "data": [
    {
      "id": "string",
      "room_id": "string",
      "started_at": "string",
      "ended_at": "string",
      "segments": 0,
      "livemode": true
    }
  ]
}

Erros: 400 401 403 429

GET/v1/transcripts/{id}#

Ler uma transcrição

Permissão: transcripts:read

Parâmetros

NomeTipoDescrição
id obrigatóriopath · string
langquery · string

Resposta 200

NomeTipoDescrição
id obrigatóriostring
room_id obrigatóriostring | null
lang obrigatóriostring
notice obrigatóriostring
segments obrigatórioobject[]
segments[].speaker obrigatóriostring | null
segments[].src_lang obrigatóriostring | null
segments[].untrusted_content obrigatórioobject
segments[].untrusted_content.text obrigatóriostring | null
segments[].untrusted_content.text_in_lang obrigatóriostring | null
segments[].at obrigatóriostring

Exemplo

curl
curl "https://api.kanutus.com/v1/transcripts/ses_4fQ2xWm9Lr7Tb1Kc8Zp3Vd5N" \
  -H "Authorization: Bearer $KANUTUS_API_KEY"
200
{
  "id": "string",
  "room_id": "string",
  "lang": "string",
  "notice": "string",
  "segments": [
    {
      "speaker": "string",
      "src_lang": "string",
      "untrusted_content": {
        "text": "string",
        "text_in_lang": "string"
      },
      "at": "string"
    }
  ]
}
