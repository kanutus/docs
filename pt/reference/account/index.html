Conta e uso

    GET/v1/me#

    Quem sou eu: organização, permissões e limites desta credencial

    Permissão: qualquer credencial válida

    Resposta 200

    NomeTipoDescrição
    credential obrigatórioobject
    credential.kind obrigatório"key" | "oauth" | "client"key = API key, oauth = app connected by a person, client = organization app
    credential.id obrigatóriostring
    credential.name obrigatóriostring
    credential.mode obrigatório"live" | "test"
    credential.needs_review obrigatórioboolean
    organization obrigatórioobject | null
    organization.id obrigatóriostring
    organization.name obrigatóriostring
    user obrigatórioobject | null
    user.id obrigatóriostring
    user.name obrigatóriostring | null
    permissions obrigatóriostring[]
    limits obrigatórioobject
    limits.spend_day_minutes obrigatórionumber | null
    limits.spend_month_minutes obrigatórionumber | null
    limits.per_call_minutes obrigatórionumber | null
    limits.requests_per_minute obrigatórionumber
    limits.spent_today_minutes obrigatórionumber
    limits.spent_month_minutes obrigatórionumber
    pricing obrigatórioobject
    pricing.api_minute_factor obrigatórionumber
    pricing.listen_text_factor obrigatórionumber

    Exemplo

    curl
    curl "https://api.kanutus.com/v1/me" \
  -H "Authorization: Bearer $KANUTUS_API_KEY"
    Node.js
    const res = await fetch("https://api.kanutus.com/v1/me", {
  method: "GET",
  headers: {
    Authorization: `Bearer ${process.env.KANUTUS_API_KEY}`,
  },
});
console.log(res.status, await res.json());
    Python
    import os, uuid, requests

r = requests.request(
    "GET",
    "https://api.kanutus.com/v1/me",
    headers={"Authorization": f"Bearer {os.environ['KANUTUS_API_KEY']}"},
)
print(r.status_code, r.json())

    GET/v1/usage#

    Uso da API por dia ou por credencial

    Permissão: usage:read

    Parâmetros

    NomeTipoDescrição
    fromquery · string
    toquery · string
    group_byquery · "day" | "credential"

    Resposta 200

    NomeTipoDescrição
    from obrigatóriostring
    to obrigatóriostring
    total_minutes obrigatórionumber
    requests obrigatóriointeger
    errors obrigatóriointeger
    data obrigatórioobject[]
    data[].daystring
    data[].credential_idstring
    data[].namestring
    data[].minutes obrigatórionumber
    data[].requestsinteger

    Exemplo

console.log(res.status, await res.json());
